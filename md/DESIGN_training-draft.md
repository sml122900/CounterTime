## §1. 컨셉 (사용자 확정)

- **프레임 = B(배분)**: 플레이어가 훈련 종목 목록에서 **3~4개를 선택**, 돌아가며 훈련.
- **능동 입력 층**: 마우스/엔터/스페이스로 **캐릭터를 직접 움직여 "내가 훈련한다"는 느낌**.
  수동 관전이 아니라 렙을 플레이어가 친다.
- **미감 = 방전**: 극한까지 밀어붙여 지치고 결국 쓰러지는 모습. 실제 유도 선수 훈련의
  "죽을 때까지 체력 쓰고 쓰러지는" 그림. 모캡으로 지친 상태·쓰러짐을 담는다.
- 즉 최종 형태는 **C(하이브리드)** — 배분(B)이 뼈대, 렙 구동은 가벼운 능동 입력.

## §2. 능동 렙 메커니즘 (지금 빌드)

한 종목 훈련 세션의 흐름:
1. 종목 선택 → 캐릭터가 Ready 자세.
2. **렙 입력**: 스페이스/엔터/클릭 1회 = 렙 1회. 누를 때마다 Rep 클립이 한 사이클 재생
   (누른 만큼 반복 = 실제로 내가 돌리는 느낌). [설계 판단 — 리듬 정확도까지 볼지, 아니면
   그냥 누르면 1렙인지. 제안: v1은 "누르면 1렙"의 단순형, 타이밍 채점 없음. 나중에 C의
   타이밍 요소를 얹고 싶으면 여기에.]
3. **피로 누적**: 렙마다 피로 ↑. 피로가 오르면 Rep이 느려지고 Strained(힘겨운 변형)가
   섞여 들어감(블렌드). 화면·캐릭터가 눈에 띄게 지쳐감.
4. **방전(collapse)**: 피로가 한계 ⚙를 넘으면 Collapse 클립 재생 — 쓰러짐. 세션 종료.
   플레이어는 쓰러지기 전까지 최대한 많은 렙을 밀어붙인다("극한까지").
5. 세션 결과(렙 수 등)는 **집계만 하고 저장 훅에 넘길 자리만**(값 연결은 (B) 이월).

- 피로 한계·증가폭·Strained 블렌드 시작점은 전부 ⚙(제안 초기치, 플레이 감으로 튜닝).

## §3. 클립 스캐폴드 — "모캡만 따면 바로 적용" (지금 빌드의 핵심)

**요구**: 사용자가 QuickMagic으로 종목 클립을 따오면, 인스펙터에서 슬롯에 넣기만 하면 동작.

**Unity 구조 (권장, 구현 시 클로드 코드가 확정)**:
- **공통 훈련 Animator Controller** 하나: 상태 `Ready → Rep(loop) → Strained → Collapse`.
  전이는 렙 입력·피로 값이 구동. 이 컨트롤러 하나가 모든 종목의 "골격".
- **종목별 Animator Override Controller** 에셋: 위 4상태의 클립을 종목별로 교체하는 슬롯
  (`RepClip`, `StrainedClip`, `CollapseClip`, 필요 시 `ReadyClip`). 종목 하나 = 오버라이드
  에셋 하나.
- **지금은 전부 placeholder 클립**(기존 Mixamo/단순 클립 재사용). 사용자가 모캡 클립을
  슬롯에 드롭 → 즉시 그 종목이 실제 동작. **코드 수정 없이 인스펙터 할당만으로 적용**.
- 종목 목록·선택·렙 입력·피로·방전은 이 오버라이드 위에서 종목 무관하게 동작 →
  종목 추가 = 오버라이드 에셋 +클립 슬롯 채우기, 코드 변경 0.

**모캡 절감 팁**: `CollapseClip`(방전)은 종목 무관하게 비슷하니 **공용 1개로 시작 가능**
(종목별 개성 원하면 나중에 교체). 즉 최소 모캡 = 종목별 Rep 1개 + 공용 Collapse 1개 +
(선택) 공용/종목별 Strained 1개.

## §4. 종목 목록 (스캐폴드에 슬롯으로 넣어둘 것)

사용자 원안 + 배틀로프 + 조사 보강. **선택 목록**(플레이어가 3~4개 고름):

| 종목 | 렙 동작 성격 | 비고 |
|---|---|---|
| 풀업(친업/도복잡고) | 매달려 당기기 | 도복잡고는 손 가림 → 팔·등 궤적 위주 |
| 튜브 우치코미(당기기/채기/기술손) | 밴드 당겨 기술 손동작 | (B)에서 특정 기술 숙련과 연결될 자리 |
| 배밀기 | 코어/브릿지 | 그라운드·방어와 연결될 자리 |
| 원판 돌리기 | 손목/회전 그립 | |
| 파워클린(훅훅 채기) | 힙 폭발 채기 | 어깨로 다 안 올리는 유도식 |
| 악력(추 감기/교차 잡고 던져 바꿔잡기/매달려 손 교차) | 쥐기·바꿔잡기 | crushing·static·dynamic |
| 로프 오르기 | 팔·그립 전신 | |
| **배틀로프** | 양팔 파상 휘두르기 | **신규 추가**, 방전 그림이 특히 잘 나옴 |
| 넥 하니스 | 목 저항 버티기 | 조사 보강, 던지기 안정성 |
| 파머스 워크 | 무거운 것 들고 걷기 | 조사 보강, 정적 그립 |
| 핀치 그립(원판 집기) | 손가락 집어 홀드 | 조사 보강 |
| 저항 던지기(메디신볼/샌드백 안고 메치기) | 실제 던지기 동작 | 조사 보강, **경기 모캡 예비 재활용 여지** |
| 스쿼트/데드리프트 | 하체 폭발 | 조사 보강, 유도 특화 아니나 기반 |

- 스캐폴드엔 **전 종목 슬롯을 만들어두되**, 클립은 사용자가 따는 대로 채움. 안 채운 종목은
  placeholder로 동작(비어도 크래시 없게).
